Method

  • DataThe five synthetic accounts in fixtures/accounts: healthy, learning, shared-budget, cold-start and stop-loss. Each has two campaigns at a $100 daily budget. PULSE's plays are in examples.
  • Modelglobal.anthropic.claude-sonnet-5-5 on Amazon Bedrock (Converse API), default sampling, no tools, maxTokens 2000.
  • PromptThe account, currency, timezone, fetch time, window, and for each campaign its status, start date, daily budget, budget kind, learning status and 30 daily metric rows: everything PULSE's core receives. The instruction is neutral, “Recommend today's daily budget for each campaign. Reply with JSON only.” No PULSE rules are in the prompt.
  • Runs10 independent runs per fixture, 50 calls, all parsed. 179,850 input and 63,587 output tokens.
  • Filesrun.py (prompt and runner), raw/ (all 50 replies), analyze.py, results.json, results.txt and the bench README.

What this does not show

  1. Freeform Claude never exceeded the total budget, and it leaned toward cutting.
  2. On the healthy fixture Claude often noted that each campaign spends $50 a day against a $100 budget, so raising the budget may add nothing. PULSE still proposes +20%. That point is fair against PULSE.
  3. The fixtures contain no missing values, so “missing numbers never become zeros” was not tested here.
  4. Synthetic data, one model, one neutral prompt. This is a consistency and guardrail comparison, not a revenue-lift claim, and not a live-account result.
